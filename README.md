# benzeen.app

Website for Benzeen_, the UAE car-cost app: landing page (English and Arabic), guides to UAE fuel prices, Salik and Darb tolls, traffic fines, Mulkiya renewal and service intervals, plus about, support and privacy pages.
Plain HTML and CSS, served by GitHub Pages. The source lives in the app project under docs/site; the guides are generated by tools/site/build_guides.py there, and tools/site/check_site.py checks the site before each publish.
The guides carry Google AdSense ads (the app never does); the publisher and ad-unit ids live in `ADSENSE` in build_guides.py, and docs/AdSense.md has the set-up.
